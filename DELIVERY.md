# FundiPulse API - delivery plan

Backend API for FundiPulse, a mobile-first construction workforce platform for
Kenya. Built and reviewed as a series of pull requests against `main`.

`main` is always expected to be releasable: a phase is merged only once its
tests, linting and migrations pass.

| Phase | Scope |
| --- | --- |
| 1 | Architecture, data model, migrations |
| 2 | Authentication, authorisation, users |
| 3 | Worker profiles, trades, skills, projects, experiences |
| 4 | References, verification, credentials, audit logs |
| 5 | Organizations, employer search, jobs, applications |
| 6 | File security, rate limiting, hardening |
| 7 | Full test suite, coverage, static analysis |
| 8 | Docker, CI/CD, Render readiness |

Full documentation arrives with Phase 1.
